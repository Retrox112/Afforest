# Afforest
Afforest is a web wrapper based app that i created as a little passion project.
at times, the code demanded blood sweat and tears but nonetheless, its a pretty good, although a little buggy application.

its an application designed such that people all over the world can use it to log trees at their surroundings and/or log trees they planted themselves.
they can take a picture of the tree and log its location, the type of tree and its age. this data is stored in a supabase cloud database, and can be acessed by anyone through the app, you can look at the location of trees, and collect data by using the pin+radius or the freehand draw with which you can draw onto a certain area to know some stats of the trees in the area.

its a simple app, hope you enjoy using it.

ive only released the android ver. but feel free to fork this repo and use PWABuilder to generate an ios installer, this is opensource with no need for attribution.
